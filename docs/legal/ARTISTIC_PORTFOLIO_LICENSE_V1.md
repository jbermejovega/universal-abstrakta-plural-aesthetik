# PACA ARTE · Proposed strong artistic portfolio license V1

**STATUS: PROPOSED, NOT APPLIED TO ANY ASSET.** This is not a replacement for the repository's existing MIT LICENSE.

## Design choice for publishable original art

The suggested standard for **specifically enumerated, rights-cleared new artistic works** is **Creative Commons Attribution–NonCommercial–NoDerivatives 4.0 International (CC BY-NC-ND 4.0)**.

Official terms: <https://creativecommons.org/licenses/by-nc-nd/4.0/legalcode>.

The holder keeps copyright. Others may share unchanged copies for noncommercial purposes with required attribution and license notices; public redistribution of adaptations and commercial uses require separate authorization. Some permitted statutory uses and rights of third parties remain outside this grant.

This is deliberately **not** the OSI Artistic License 2.0, which is a software license. For private unreleased code, and for original works that should not have even noncommercial redistribution rights granted, use an individually scoped **All rights reserved** policy after legal review, not CC BY-NC-ND.

## Scope is positive, never inherited

The license applies **only** to an asset with all of:
- exact relative path + content SHA-256 and first-publication date;
- named rightsholder(s), proof of authorship/assignment or authorized sublicensing;
- declared `license: CC-BY-NC-ND-4.0`;
- written human review receipt and source/provenance ledger;
- no preexisting inconsistent inbound license.

There are **zero cleared artistic assets** in the V1 rights register. No existing `demo/`, `src/`, screenshots, archived game bundles or upstream dependency is hereby relicensed. If artwork is mixed with MIT code or a licensed font, make the different scopes visible next to the work and in the downloadable package.
