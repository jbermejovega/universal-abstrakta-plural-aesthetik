# Pala Estaca Godot projection

`PalaEstacaGraphEngine.gd` loads a JSON manifest generated by `projectSceneToGodotManifest`.

## Minimal scene

1. Add a `Node3D` to a Godot 4 scene.
2. Attach `PalaEstacaGraphEngine.gd`.
3. Write the generated manifest to `res://pala_estaca_scene.json`.
4. Run the scene.

The runtime creates:

- sphere meshes for vertex cells;
- finite mesh carriers for edge, facet and higher cells;
- cylinder relations for incidence and boundary maps;
- `Label3D` overlays for higher-cohomology support.

## Boundary

```text
manifest = deterministic renderer contract
Godot scene = interactive projection
render != canonical code object
render != quantum execution
```

The loader rejects manifests that do not preserve `noIdentityTransport`, `renderIsProjection`, and `canonicalAuthority: false`.
